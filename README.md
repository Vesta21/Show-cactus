# Snow-cactus

Мод добавляет в игру декоративный блок «Снежный кактус».

## Требования к совместимости
- **Версия Minecraft:** 1.21.1
- **Загрузчик:** Fabric Loader 0.16.5+
- **Зависимости:** Fabric API (версия 0.116.17+1.21.1)

## Установка
1. Установите совместимую версию Minecraft и Fabric Loader.
2. Поместите файл `snow_cactus-1.0.0.jar` в папку `mods`.
3. Установите Fabric API в папку `mods`.
4. Запустите игру.

## Использование
- **Получение:** Блок можно скрафтить в верстаке (8 снежков по кругу и 1 зеленый краситель в центре) или получить командой `/give @p snow_cactus:snow_cactus`.
- **Свойства:** Блок имеет прочность 2.0, свечение 10 (излучает свет) и сопротивление взрыву 6.0.
- **Дополнительное поведение:** При клике правой кнопкой мыши по блоку в чате появляется сообщение «Снежный кактус приветствует вас!».

## Известные ограничения
- Мод не поддерживает версии игры ниже 1.21.1.
